# `maibot-living-rhythm` — MaiBot 拟人作息、现实锚点与主动社交插件

面向**原生零第三方依赖** MaiBot（`1.3.19`–`1.4.99`，SDK `2.20.0`–`2.30.99`）的独立扩展插件。不绑定固定人设，无需改动宿主机源码，开箱即用。

## 核心功能

1. **昼夜作息状态机与深夜休眠 / 睡醒爬楼**
   - 内置 7 段昼夜状态机（深夜休眠、刚睡醒爬楼、上午、午休干饭、下午、晚间活跃、睡前犯困）。
   - 进入设定休眠时段（默认 `01:00–07:30` `Asia/Shanghai`）自动调用宿主原生 `frequency.set_adjust(0.0)` 静默入站写记忆、不唤醒主脑，并由 `send_service.before_send` 兜底拦截。
   - 休眠期收集 `@`/别名/提问等高价值未读消息，醒来后精选补回。
2. **QQ 在线状态与私聊输入态（自动探测适配器）**
   - 运行时自动通过 `api.list()` 探测宿主已安装的 OneBot / NapCat / SnowLuma 适配器，无须硬编码插件 ID；无支持该动作的 QQ 适配器时自动跳过。
   - 作息时段切换时自动调用 `set_online_status`（睡觉中、学习中、干饭中、听歌中、离开等）；私聊触发回复前自动触发 `set_input_status` 模拟「正在输入...」。
3. **清醒期自动回戳**
   - 被戳一戳时按概率与冷却调用 `send_poke` 回戳。
4. **现实锚点与圈层动态雷达**
   - **城市天气与日历节点**：支持绑定任意国内城市（默认上海）拉取实时天气（腾讯天气 + wttr.in 双源），并内置法定节假日、自定义调休补班日、考试季与 618/双11 节点。
   - **圈层动态低频抓取**：按可配置兴趣标签每 4 小时低频从 B 站热搜与分区榜单抓取少量动态缓存，聊到对应标签或冷群破冰时自然带出。
5. **冷群破冰与可控白名单私聊**
   - 群聊冷场超过阈值后按每日限额冒个泡破冰；可选开启白名单熟人轻私聊（默认关闭且白名单为空）。

## 安装与配置

1. 在 MaiBot 插件市场安装本插件（`github.yunshanluan0714.living-rhythm`）并重启或热加载。
2. 在 WebUI 插件管理页按需调整作息时间段、绑定城市、兴趣标签与白名单配置。
